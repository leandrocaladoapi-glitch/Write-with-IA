# Write with AI

**A Practical Manual for AI-Assisted Fiction Writing** *(working title)*

A long-form practical manual (~300+ pages) that teaches **beginner fiction writers**
both the fundamentals of storytelling **and** how to use AI as a writing partner —
step by step, with prompts, exercises, and complete workflows.

## The promise

By the end of this book, a complete beginner will be able to:

1. Understand story fundamentals (premise, stakes, structure, character, scene).
2. Use an AI assistant effectively at every stage: idea → outline → draft → revision.
3. Keep their own voice and judge AI output critically.
4. Navigate ethics, disclosure, and publishing basics.

## How we work

1. **Methodology first.** Research follows [`docs/research-methodology.md`](docs/research-methodology.md):
   define before searching, go to the primary source, seek counter-evidence,
   record uncertainty.
2. **Every factual claim is registered.** No claim enters the manuscript without a row
   in [`research/claim-register.md`](research/claim-register.md): evidence, source
   type, confidence, last verification.
3. **We eat our own cooking.** The book teaches AI-assisted writing, so the manuscript
   itself is written that way — and our AI use is logged transparently
   (future Appendix F).
4. **Chapter lifecycle:** `scaffold → outline → draft → revision → final`.
   Definitions of done live in [`book/status.md`](book/status.md).
